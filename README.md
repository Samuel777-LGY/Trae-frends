# 露营批发部（纯前端演示版）

菜市场大字报风的露营装备批发展示页。只做前端，不需要 Node、不需要数据库、不需要启动服务。

## 查看方式

直接双击打开 `public/index.html`，或把文件拖进浏览器即可。

- 商品数据内置在 `public/js/api.js`，页面打开即展示 18 件商品。
- 订单、加减、折扣、小票、历史记录均为前端模拟，结果存在浏览器 `localStorage`，不会请求后端。
- 外网字体或 Tailwind CDN 加载失败时会自动回退系统字体，不影响页面展示。
- 顶部工具条可进入「后台账房」模拟后台。
- 桌面端支持鼠标跟随交互：价签随指针轻微透视倾斜并带光斑，横幅视差与光晕跟随，按钮磁吸偏移。

重置演示数据：浏览器控制台执行 `localStorage.removeItem('camp-wholesale-orders-v1')` 后刷新。

## 页面内容

前台 `index.html`：

- 顶部工具条、红底黄字横幅、「今日开市」印章、无限循环的黑色跑马灯
- 六类 18 件商品：帐篷、睡袋、炊具、桌椅、灯具、配件收纳
- 牛皮纸价签卡片、随机微倾斜、悬停回正、胶带与红印章细节
- 分类切换、数量加减、库存售罄状态
- 底部批发车栏：件数、原价合计、折后应付、阶梯折扣提示
- 菜市场小票弹窗与历史小票抽屉
- 摊主套装、批发四步、批发须知、档口信息、买家留言等扩展展示区

后台 `admin.html`（模拟数据，无真实接口）：

- 今日营收、订单数、售出件数、库存预警四张统计卡，数字滚动入场
- 订单流水表格：单号、时间、件数、折扣、实付、状态标签
- 库存看板：库存比例条与「库存偏低 / 已售罄」标记
- 营收概况：近 7 日柱状图与分类占比条

## 文件

```
camp-wholesale/
├── public/
│   ├── index.html        # 前台摊位
│   ├── admin.html        # 模拟后台账房
│   ├── css/
│   │   ├── style.css     # 菜市场大字报视觉与交互动效
│   │   └── admin.css     # 后台看板样式
│   └── js/
│       ├── api.js        # 内置演示商品 + localStorage 模拟数据库
│       ├── main.js       # 前台渲染与购物逻辑
│       ├── interact.js   # 鼠标跟随、倾斜、磁吸、分类指示条
│       └── admin.js      # 后台模拟数据与图表
├── server.js             # 早期可选后端，演示不需要
├── data/                 # 早期可选数据文件，演示不需要
└── package.json
```

## 视觉规范

- 配色：牛皮纸米白 `#f7f0e1`、大红 `#d62828`、明黄 `#ffd23f`、墨黑 `#1a1a1a`、草绿 `#5a8c4a`
- 标题/价格：Noto Sans SC 900；标语/印章：Ma Shan Zheng；小票：Courier New
- 3px 粗黑描边、非对称圆角、硬阴影、纸张噪点纹理
- 跑马灯为双组内容无缝循环，鼠标悬停暂停
- 卡片错峰入场、金额变化回弹、小票弹入，均支持 `prefers-reduced-motion`
